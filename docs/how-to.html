Start here

Everything lives in your browser, not on a server. Nothing is uploaded, nothing is shared until you press Save and hand someone the file.

That is the single most important fact about this tool, and it cuts both ways: your work is private by construction, and it is gone if you clear browser data without saving. Save early, save often, keep the JSON somewhere real.

Five minutesThe shortest path to something useful

If you read nothing else, read this. Six moves take an empty workspace to a chart you can hand to someone.

  1. Press Demo once.

    Bottom of the right rail. It fills the workspace with a worked example — a portfolio chart, a roster, two task flows. Poke at it, break it, then press Clear when you want your own. Learning on real rows beats learning on an empty grid.

  2. Make your chart.

    The + on the chart-tab bar asks which kind you want. Organization chart if the columns are your real directorates and you want roster links and fixed Portfolio → Program → Project → Task tiers. Free-form if you want to name your own columns and nest as deep as you like. You can have as many chart tabs as you want, of either kind.

  3. Type your top-level activities.

    + Add portfolio activity at the foot of the table. Click any name to edit it in place; Enter commits, Esc backs out.

  4. Fill the cells.

    Click a cell, pick letters. One A per row, at least one R — the tool will tell you when a row breaks that, and where.

  5. Drill.

    The ▶ at the left of a row opens a new pane for its breakdown, one tier down. That is the nesting: the row's R becomes the A of everything inside it.

  6. Save.

    💾 Save downloads one JSON file holding every chart tab, the roster, every flow, and any attached documents. That file is your work.

The chartBuilding the matrix

The chart screen is a stack of panes. Each pane is one tier of one branch of the work, and drilling opens the next one below it.

▶ Drill into a row

Opens that row's breakdown in a new pane. Keep going and the panes cascade — the breadcrumb band at the top of the screen is your trail back. Click any crumb to jump.

⊞ Add a column

Free-form charts only: name your own party columns right in the header. Organization charts share one fixed set of columns across every chart, because that is what makes them comparable.

✎ Rename anything

Activity names, column headers, tier labels and chart-tab titles are all edit-in-place. Click, type, Enter.

◫ Details & documents

Details in the right rail opens a panel for the selected row: a definition in prose, and files attached straight to the row. Files are stored in the browser and travel inside the saved JSON.

Two rules the tool actually enforces

Exactly one A per row. Two accountable parties is the same as none — nobody can be asked. At least one R. A row nobody does is a row that will not happen. Break either and a pin appears on the row, a count appears bottom-left, and clicking it jumps you to the offender. Nothing is ever blocked — the tool flags, you decide.

Two doers? Then say which one cascades. When a row has more than one R, mark one primary — that is the column whose accountability drops into the tier below. Without it the cascade has to guess, and the tool will ask.

The rosterWho the columns actually are

A column header says Cyber & EW Directorate. The roster says which division, which branch, which team, and which people.

Build it top-down: directorate → division → branch → team → people. Once a directorate is mapped to a column, every cell in that column can name the real unit behind the letter — and the Tasks lens can answer "what lands on my branch?" for a unit four levels down.

This is optional. A chart with no roster still works; it just cannot tell you who, specifically.

Entities — the parties that are not in the tree

Plenty of real parties are neither a person nor one of the six directorates: a board that approves, a committee that reviews, a vendor that delivers, a standing team that spans two directorates. Those go in the Entities section at the bottom of the Roster.

An entity is deliberately flat. It has a name, a kind, a short label and whoever speaks for it — and nothing underneath. That is the point: it names a party at exactly the depth RACI already stops at, without pretending it sits somewhere in the org tree it does not belong to.

Once one exists it is assignable anywhere a directorate is. In the Responsible Party panel, the first dropdown switches between Directorate and Entity; on a Program or Project row, the org badge's list has an Entities group at the bottom. Each card shows how many things name it, and deleting one that is in use tells you exactly what would be left pointing at nothing.

Task flowsBelow the chart's bottom row

A chart Task row says who owns a task. A flow says how it runs: steps, handoffs, decisions, and what counts as started and finished.

Make one+ New Graph

Starts an empty flow in Free-Form mode. + Add task drops a step on the canvas.

Wire it updrag a socket

Every step has a socket each side. Drag from an out socket to another step to create a handoff. Click the noodle to name the deliverable it carries, or the branch condition.

Route itdrag the noodle

Drag any handoff line itself and it bends around whatever is in the way, leaving a redirector handle. Drag the handle to steer, double-click it to remove. Purely visual — the handoff is still A to B.

Frame it⊟ Group

Select steps (click, then shift-click; or shift-drag a box) and wrap them in a labelled frame. Collapse the frame and it folds into one box whose sockets are its real boundary crossings.

Two modes, and the difference matters

The strip above the canvas both states the mode and sets it — the picker on its right is the label. Free-Form: each step's RACI is typed on the step. Right for a tabletop, a dry run, work with no chart row yet. Chart-Linked: every step names the chart row it implements and reads that row's letters live, so a chart edit reaches the flow immediately. Switching is lossless both ways.

Groups hold on to their steps. Drag a step around inside its frame and the frame grows to follow it — you cannot lose a step out of a group by moving it. To take one out deliberately, hold Alt (⌥ on a Mac) while dragging; the frame freezes and goes amber, and the step lands wherever you drop it. The frame tells you so itself while you drag.

Flows reuse flows. The gallery (⊞ Gallery) shows every flow in the workspace by shape. Click one to open it; drag one onto the canvas and it becomes a single box standing in for that whole flow — a reference, not a copy, so an edit over there shows up everywhere it is used.

TasksReading it back, one unit at a time

Charts and flows are organized by the work. The Tasks lens flips that: pick an org unit and see every chart row and every flow step that lands on it.

Each item carries what it needs to be actionable — the roles that unit holds, what arrives as input and from whom, and what leaves as output and to whom. This is the screen to hand a branch chief who does not care about the portfolio picture and wants to know what is on their plate.

LifecycleDraft and Final

Every chart and every flow carries a status, and both states are always labelled — a marking that appeared only when something was wrong would teach everyone to read "no marking" as "approved".

Draft is a working copy: still being written, free to change. Final means someone signed it, and the tool locks it — the add, delete and rename affordances are taken away, the cells go inert, and anything that tries to move on a Final artifact is put back whatever path produced it. Reopen it as a draft to edit again.

Status rides on each artifact, not the workspace, because a settled chart with three exploratory flows hanging off it is the normal case. One cross-check runs anyway: a Final flow reading rows from a Draft chart is flagged per step, since the ground can still move under a claim that reads as settled.

DetailsMetadata, and why the filter box gets better

Every chart and every flow carries the same small block: description, customer, priority, budget and tags.

Open it with ✎ Details — on the chart-tab bar for a chart, on the strip above the canvas for a flow. A dot on the button means something is filled in.

It is not decoration. The gallery's filter box matches every one of those fields, so typing a customer name, a fiscal year or a tag narrows the list the same way typing a flow name does. Tags show on the gallery cards. All of it rides into the Excel export as columns on the Document sheet and into the XML as a <meta> element, so the answer to "what is this and whose is it" survives leaving the tool.

A Final chart or flow shows its details read-only. The lock is about editing, not about reading.

Getting data in and outSave, Load, Merge, Ingest, Export

💾 Save / 📂 Load

One JSON file, everything in it. Load replaces the workspace.

⧉ Merge

Adds another file's charts and flows to this workspace as new tabs, instead of replacing.

🤖 Ingest Kit

Downloads a briefing document. Hand it plus your raw notes, spreadsheet or slides to any LLM and it writes a JSON file you can Load or Merge.

Export gives you the document forms: Print/PDF for a clean chrome-free layout, PowerPoint with one slide per tier, Excel for spreadsheet review, XML for anything programmatic, and Mermaid for diagramming.

AppearanceFive themes

The theme picker sits in the right rail. Dark is the default and stays the default — an unset preference is never resolved against your operating system, so this tool looks the same on a fresh machine whatever that machine is set to.

Light re-picks the hues for paper. The three High contrast variants share one contract — flat backdrops, no texture, full-weight rules, always-visible focus — and differ only in palette: Light for a bright room or a projector, Dark for a dark one, Neon for maximum separation on a screen. These guides follow whichever you pick.

When something looks wrongRead the warnings

The count in the bottom-left corner is the rule engine. It is never a blocker — it is a reading list.

Click it and it walks you to each finding: rows with no accountable party or two of them, rows nobody does, cascades with an ambiguous primary, over-consulted rows, flow steps in Chart-Linked mode that name no row, and steps pointing at a chart row that has since been deleted. Every one of them names the thing and jumps you to it.

Lost work?

Everything lives in this browser. Clearing site data, a private window closing, or a different machine all mean an empty workspace. There is no server copy. Press Save and keep the file.
