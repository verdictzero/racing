The seven that matter most

If you read nothing else this week, read these.

0.32

Nothing is signed until someone signs it

Every chart and every flow now carries Draft or Final, and both states are always labelled. Final locks the artifact three ways over, and every export carries the status through — including a diagonal DRAFT watermark on paper.

0.31

A flow can now be tied to the chart

Chart-Linked mode makes every step name the org-chart row it implements and read that row's letters live, so a chart edit reaches the flow immediately. Free-Form stays for tabletops. Switching is lossless both ways.

0.29 · 0.34

One theme became five

Light and High Contrast joined Dark, then High Contrast split into a family of three — Light, Dark and Neon — sharing one structural stylesheet. Your stored preference migrates; nothing resets.

0.35

Handoffs can be routed around obstacles

Drag any noodle and it bends, leaving a redirector handle you can steer or double-click away. Routing is pure geometry — the handoff is still A to B, so nothing that reads the graph is affected.

0.38

One place for every named thing

The Object Gallery is a third system in the rail: the catalogue the chart and the flow both point at. Deliverables and entities in one browser, with the answer to "where is this used?" on the card you click.

0.37

Excel is a way in, not just a way out

Download a blank template, fill it in, and load it back — the picker takes a .xlsx anywhere it took a .json. It is the same shape the Excel export writes, so export, edit in a spreadsheet, and bring it back is a closed loop.

0.36

A party no longer has to be a directorate

Boards, committees, vendors and standing teams are first-class parties now, created in the Roster and assignable anywhere a directorate is. Flat by design — they name a party at the depth RACI already stops at, without pretending to sit in the org tree.

Release by release

In order, with the reasoning where the reasoning is the interesting part.

Fri 7 Aug

Themes, then reuse and structure for flows.

0.29

Light and High Contrast join Dark

  • New
    Three application themes, picked from a segmented control in the toolbar; arrow keys move through it. The choice is a device preference, not document data — it stays out of the exported JSON and survives Load, Merge, Demo and Clear, so opening a colleague's chart never repaints your app.
  • Fixed
    No dark flash on load. An inline <head> bootstrap puts the stored theme on <html> before the first paint.
  • Changed
    Dark stays the default, always. An unset preference is deliberately not resolved against the operating system, so a fresh browser always opens dark.
0.30

A gallery, nested flows, mating points, groups

Four features that together let a flow be reused instead of retyped.

  • New
    Flow gallery. Every flow in the workspace as a card carrying a sketch of its actual graph, its counts, and its chart anchor. The dropdown answers "which one is it called". The gallery answers "which one is it".
  • New
    Nested flows. Drag a card onto the canvas and it becomes one box standing in for that whole flow — a reference, not a copy, so one edit updates every host. Reference loops are blocked at the source and flagged if one arrives by import.
  • New
    Per entry/exit mating points. A nested box gets a socket per entry and per exit of the flow inside, so a procedure that ends two ways can feed two different next steps. Ports store the selection, not a count, and empty means "all of them" — so a host keeps following the referenced flow as it grows instead of silently re-wiring.
  • New
    Groups. Labelled frames around steps: visual, conceptual, and functional — collapse one and it folds into a single box whose sockets are its real boundary crossings.
  • Fixed
    Flow noodles follow the theme. They were still using baked colour literals, so the canvas ignored Light and High Contrast.
Tue 11 Aug

The two structural features of the week.

0.31

Flows get two explicit modes

  • New
    Chart-Linked mode. Every step names the org-chart row it implements and reads that row's RACI live — no copy, so a chart edit reaches the flow immediately. A step with no row is an error, not a gap: that is the mode's whole contract.
  • New
    Free-Form mode is what every flow was before, and stays the default — right for a tabletop, a dry run, or work not yet mapped onto the chart.
  • Changed
    The rail says these are two systems. The task flow got its own outlined, tinted box away from Chart / Roster / Tasks.
0.32

Draft and Final, and what Final locks

Two states, one question: is this still being written, or has someone signed it?

  • New
    Status on every chart and every flow, shown on the chart tabs, the flow picker, the gallery cards, and a permanent strip above the canvas. Both states are labelled, always. A DRAFT marking that appeared only when something was wrong would teach people to read "no marking" as "approved" — the exact failure this exists to prevent.
  • New
    Final locks the artifact three ways over: affordances removed at render, fields made inert, and a capture-phase gate for what neither reaches — keys typed into a focused field, the delete shortcut, drag, drop and paste. Behind all of it, a check on every save puts back anything that moved, whatever path produced it. An accident guard, not a permission system: one click lifts it, nothing is destroyed, and undo steps back through a finalize like any other edit.
  • New
    Draft and Final cross. A Final flow reading rows from a Draft chart is a settled claim resting on ground that can still move. Allowed — sign-off order is your call — but flagged per step, never silent.
  • New
    Every export carries it: a Document sheet and Status column in Excel, attributes in XML, a header line in Mermaid, stamps on PowerPoint's title and flow slides, and a diagonal DRAFT watermark on every printed page. A draft printed and circulated as if settled is how this goes wrong on paper.
Thu 13 Aug

Interaction and chrome — plus the manual.

0.33

Both systems in the rail get the same box

  • Changed
    Chart / Roster / Tasks are boxed too, in R-blue, alongside the flow's green box. 0.31 boxed only the flow, which read as "the flow is the special one" rather than "these are two systems". It is now one box component used twice, each carrying its own hue in a single token.
0.34

Flow chrome, five themes, and groups that hold on

  • Changed
    The mode picker is now the strip's label — right-justified, where the badge used to be. It was two places to read one fact and two to keep in step.
  • Heads-up
    Flows are RACI only. DACI and RAPID are gone from task flows. Charts keep RACI and RASCI. A flow's steps are execution work, and the decision variants only ever split the vocabulary of a tool whose point is one responsibility language across chart and flow.
  • New
    High Contrast becomes a family of three: Light (white paper, black rules, hues deepened rather than brightened), Dark (the previous palette, unchanged), and Neon (near-black violet ground with cyan, hot pink, electric yellow and lime at full voltage). All three share one structural stylesheet through a prefix selector, so a new variant is a palette and a picker entry — nothing else.
  • Fixed
    Group membership survives a drag. A step used to leave its frame the moment it was dropped past the frame's edge — and the frame froze mid-drag, so that edge was wherever it had been when you started. Rearranging inside a group lost steps out of it. Now the frame follows its members live and the step stays put at any distance. To take one out, hold Alt (⌥) while dragging; the frame freezes and goes amber, and says so in its own header while you drag.
0.35

Redirectors, chrome fixes, and the manual

  • New
    Redirectors on a handoff. Drag any noodle and it bends around whatever is in the way, leaving a handle you can drag again or double-click to remove. A click without travel still opens the handoff popover. Routing lives on the edge, not in the task list. A routed handoff is still one handoff from A to B — so derived inputs and outputs, group boundary crossings, the flow table, the rules and all five exports are untouched by how the line gets there.
  • New
    A third field guide: the manual. Every screen and every gesture in the order you meet them, plus a cheat sheet of the ones clicking around will never reveal.
  • Fixed
    The product name no longer wraps in the right rail. It widened to 244px and the version chip drops to its own line — a title snapped into "ASIC / RACI / Tool" reads as three words, not one product.
  • Fixed
    The breadcrumb's tier label is legible on every theme. It was painted in ink at 62%, which works only while every tier fill is bright; the new light high-contrast theme deepens its fills and the label went dark-on-dark.
  • Fixed
    Hiding the flow gallery now names the way back. The ⊞ Gallery button always reopened it, but an × with no hint reads as a one-way door.
0.36

Non-person parties, and metadata on everything

  • New
    Entities — boards, committees, vendors, standing teams. Created in a section at the bottom of the Roster, and assignable anywhere a directorate is: the Responsible Party panel switches between Directorate and Entity, and a Program or Project row's org list gained an Entities group. The roster models six fixed directorates and the people inside them. A PG Board is neither, and until now the only way to name one was to fake it as a division or spend one of the six slots. An entity is deliberately flat — no divisions, no people under it — because it names a party at exactly the depth RACI already stops at.
  • New
    Entities count their own uses. Each card says how many things name it, and deleting one that is in use lists what would be left pointing at nothing before you commit. References are not rewritten on delete. They read “(missing entity)” until re-pointed — the same contract a deleted deliverable already had, and the honest one: a party that quietly emptied itself would be worse than one that says it is broken.
  • New
    Details on every chart and every flow. Description, customer, priority, budget and tags, in one panel opened with ✎ Details — on the chart-tab bar for a chart, on the strip above the canvas for a flow. A dot on the button means something is filled in.
  • New
    The filter box got much better. It matches every metadata field, not just name and description, so a customer name, a fiscal year or a tag narrows the gallery. Tags show on the cards.
  • New
    Both new blocks export. An <entities> element and a <meta> element in the XML; an Entities sheet and five new columns on the Document sheet in Excel.
  • Fixed
    A Final artifact shows its details read-only rather than hiding them. The lock is about editing, not about reading.
0.37

Excel comes back in, and a template to start from

  • New
    Import a .xlsx. The file picker takes a workbook anywhere it took a JSON file. Charts can now come back out of a spreadsheet, not only go into one. Export has existed since 0.19, so the tool was a place work went to rather than a place it could return from. A .xlsx is a ZIP of XML, and the browser's own DecompressionStream is the inflater — which is why this ships with no library.
  • New
    A blank Excel template, under Export. One flat sheet: the first columns are the hierarchy, the rest are your parties. Each row repeats its ancestors and the deepest filled cell names the row being defined; naming a parent on a child's row creates it. It is deliberately the same shape the Excel export writes, so export → edit in Excel → load back is a closed loop rather than two formats that happen to share an extension.
  • New
    It reads real spreadsheets, not just its own template. The header row is found rather than assumed to be row 1, so a title and a note above the table are fine. Blank rows and extra columns are ignored, letters are case-insensitive, and your party column headers become the chart's column labels.
  • New
    Rows that cannot be placed are reported, not guessed at. A row with Project filled and Program blank has no sensible home, so it is skipped and counted in the summary.
  • New
    Every import lands as a new chart tab, behind a confirmation stating what was found. Nothing already in the workspace is touched, so Load and Merge mean the same thing for a workbook.
0.38

The Object Gallery

  • New
    A third system in the mode rail, in its own box below Task Flows and set apart by a rule. The chart is who owns what, the flow is how work moves, and this is the catalogue of the things both of them point at. Nothing new is modelled. Two flat registries already existed and neither had a home worth the name — deliverables were reachable only through a slide-out Legend panel, entities only through a section at the bottom of the Roster. They are the same kind of thing, so they belong in one browser.
  • New
    The detail pane answers "where is this used?" Click any card and every place in the workspace that names that object is listed — each one a button that opens the chart or flow it belongs to. Both reverse indexes were already being computed for the rules engine. This is the first screen that shows them.
  • New
    Filter and facets. Match on name, type or description, or narrow to deliverables or entities. Create, edit and delete either kind in place — a deliverable with uses cannot be deleted, an entity can, and anything still naming it reads “(missing entity)” until re-pointed.
  • New
    The demo seeds both registries — four deliverables carried on the tabletop's handoffs, two entities. A gallery that is empty the first time you open it teaches nothing about what belongs in it.

Worth knowing before you open an old file

Three changes that touch existing data

A flow saved as DACI or RAPID now loads as RACI.
The framework picker is gone from task flows, and normalization coerces the value on load rather than leaving state with no way to see or change it. Letters outside RACI are preserved in the cells but are no longer offered. Charts are unaffected — RACI and RASCI both remain.
The old "Contrast" theme is now "High contrast · Dark".
Same palette, new name. A stored preference migrates automatically in both the pre-paint bootstrap and the main script, so nobody gets reset to Dark.
A flow's description moved into the new details block.
It was the only metadata a flow had; charts had none at all. Both now carry the same block, so one panel edits either and one predicate searches both. An older file's top-level description is folded into meta.description on load — nothing is lost and nothing needs re-typing.
